Ali CW-10 · PR #1128, part 1 of 2 Open PR

Keep GitHub and Forgejo apart

Why: Pawtograder's background jobs assume every repo is on GitHub. A Forgejo repo must never reach them.

  • Every assignment and repo records its host. GitHub stays the default.
  • Forgejo needs the cloud-workspaces course flag. The host locks once repos exist.
  • GitHub-only jobs skip Forgejo rows: repo creation, permission sync, invites, webhooks.

Naman CW-15 · PR #1153, part 1 of 3 Open PR

Only accept grades from runners we trust

Why: After a push, a CI job runs the grader and reports the score. The job proves where it came from with a signed token. Pawtograder has to check that token before it records a grade.

  • Checks the token's issuer, signature, and audience.
  • GitHub and our Forgejo each use their own trusted keys.
  • Tokens from any other issuer are rejected.
Tested
15 targeted OIDC tests. All CI checks pass.
Rollback
Revert the PR. No database migration.
Next PR
Callers start accepting Forgejo tokens

github.com/pawtograder/platform/pull/1153 ↗

~40 s. Before: validateOIDCToken always fetched GitHub's keys and never read iss or aud. Now it picks keys by issuer, and a Forgejo instance is trusted only when FORGEJO_URL is set. Callers stay GitHub-only until PR 2.
